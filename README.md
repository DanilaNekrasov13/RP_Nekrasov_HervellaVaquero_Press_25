Practice assignment for Robot Programming.

## Game: Dodge the Falling Blocks

A simple arcade game where the player controls a purple character and must avoid falling enemies. The score increases over time, and the difficulty rises as enemies fall faster.

## Requirements

- Python 3
- pygame library

## Installation

Install pygame with pip:
pip install pygame

## How to Run

Run the game with:
python game.py

On macOS, you may need to use:
python3 game.py

## How to Play

- Press any key on the welcome screen to start.
- Use the **Left** and **Right** arrow keys to move the purple player.
- Avoid the red falling enemies — touching one ends the game.
- Your score increases each time an enemy falls off the bottom of the screen.
- The game gets harder over time: enemies fall faster.
- On the game over screen, press **R** to play again.

## Controls

| Key | Action |
|-----|--------|
| ← → | Move player |
| R   | Restart after game over |
